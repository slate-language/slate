## Against 0.1.8, where the speed was lost

**0.1.32 is still 30.97% slower than 0.1.8 on the geometric mean** (`alternate.pl 5`), so the gain above
recovers only part of an earlier loss. Each release against 0.1.8 (`alternate.pl 3`):

| releases | geometric mean | sysl |
|---|---:|---|
| 0.1.9 to 0.1.18 | within 1.5% | 0.0.x |
| 0.1.19 | +47% | 0.1.0-alpha.5, the first self-hosted compiler |
| 0.1.21 to 0.1.31 | +55% to +60% | |
| 0.1.32 | +31% | 0.8.8 |

`bench/fib.sl` under `/usr/bin/time -l`, which does not depend on what else the machine is doing:

| release | instructions | cycles |
|---|---:|---:|
| 0.1.18 | 5.06G | 634M |
| 0.1.19 | 7.85G | 1182M |
| 0.1.32 | 6.31G | 1017M |

The only slate source change at 0.1.19 beyond file splits is one `Buf.copy`, so the compiler is the suspect.
That has not been profiled yet.
