# 2026-09-21 — sysl 0.0.123: `Buf.push`'s grow path moves out of line — shortlist item 1

**Shortlist item 1, closed.** 0.0.123 moves `Buf.push`'s grow path `@noinline @cold`, the same move
0.0.122 made for `Buf.at`'s bounds panic, so the ordinary store-and-bump path — the common case, no
growth needed — inlines at every hot call site. This is a compiler change and nothing under `dev/`
moved: `package.hocon`'s floor is the whole diff.

**Measured: geometric mean -16.6% on the alternating best-of-9**, against the 10–15% ceiling the
second sampled profile gave it. `Buf.push<Value>`'s self time on `methods.sl` fell from **16.2%**
(dev `76128bf`, before) to **1.9%** (dev `0669746`, after) — the same measurement the profile used,
same program, same sampler.

## The witness: `Buf.push<Value>`'s share on `methods.sl`, same program the second profile used

`/usr/bin/sample` at 1 ms, `bench/methods.sl`, self time from "Sort by top of stack" against the
main thread's own sample total — identical method to the [second sampled
profile](2026-09-21-sampled-profile-2.md), which is where the "before" figure below comes from
(dev `76128bf`, sysl pre-0.0.123).

| | before (dev `76128bf`) | after (dev `0669746`, sysl 0.0.123) |
|---|---|---|
| samples (main thread) | — | 415 |
| `Buf.push<Value>` self time | **16.2%** | **8 / 415 = 1.9%** |

An 88% relative fall in the one thing this item set out to move. `run_frames`' own share rose from
30.5% to 43.6% of the same 415 samples — expected, since nothing else in the loop got slower and the
dispatch itself is what is left once the call it used to make disappears.

## What this closes and what stays open

**Shortlist item 1 (`bench/README.md`) is struck through**: "inline `Buf.push` the way 0.0.122
inlined `Buf.at`" — 18.5% weighted share, 10–15% ceiling, measured **-16.6%**, above the ceiling
estimate. Item 8 (a narrower `Value`, or NaN-boxing) still names `Buf.push<Value>` as its own
15.5%-of-wall reach figure; that number is now stale in the same direction this page's own headline
was — the sampled-profile-2 ranking should be re-taken before that item is next in line, since two
compiler-level items (this one and, earlier, `Buf.at`'s own inlining) have both moved underneath it
without a slate-side change to explain either.

**Nothing under `dev/` changed.** The whole of this item is `package.hocon`'s floor plus a newer
compiler, exactly as the 0.0.122 write-up above was.
