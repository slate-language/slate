# 2026-09-22 — sysl 0.0.124: `Buf.push` inlines outright for a counted element

**A follow-on to the 0.0.123 pickup, not a new shortlist item.** 0.0.123 moved `Buf.push`'s grow path
`@noinline @cold`, which let the ordinary store-and-bump inline at every hot call site. 0.0.124 goes
further for a **counted element** — slate's `Value`, which every array and object push in the
interpreter is — inlining the push outright rather than leaving a call to a generic instantiation.
sysl's own micro-bench reports **1.85x** on push/pop of a 40-byte counted struct. This is a compiler
change and nothing under `dev/` moved: `package.hocon`'s floor is the whole diff.

**Measured, on the tree this actually lands on: geometric mean +0.06% and +0.16% across two
alternating best-of-9 runs — a wash, not a win, on dev `24a2cb0`.** A first measurement, taken against
dev `bf4dd9b` before this branch merged `origin/dev`, read **-2.08%**; while this branch was being
measured, the `inline-fused` item landed and rewrote `run_frames.sysl`'s dispatch loop, and merging it
in and re-measuring gives the flat result below. **The -2.08% figure is stale and is not this item's
number** — see "What changed between the two measurements" below for why the mechanism still works but
no longer moves the wall clock on this tree.

### What changed between the two measurements

**`inline-fused` (dev `24a2cb0`) rewrote the same dispatch loop this item touches**, writing the four
`fused_*` superinstruction arms out inline in `run_frames.sysl` instead of calling out to
`run_fused.sysl`. That is a real slate-side code change to the function `Buf.push<Value>`'s callers sit
inside, and it moved underneath this item between the first and second measurement — the first reading
(-2.08%) was taken against dev `bf4dd9b`, the commit before `inline-fused` landed. The witness below
shows the compiler mechanism still works exactly as designed; what changed is that the dispatch loop
around it is now shaped differently, and on *this* shape the wall-clock effect nets out near zero, with
several programs (`branches`, `arrays`, `reals`, `csv`) reading slower rather than faster. Nothing in
`package.hocon`'s own diff changed between the two measurements — only the dev tree it was measured
against did, per this branch's own re-gate rule.

## The witness: `Buf.push<Value>`'s self time on `methods.sl`

`/usr/bin/sample` at 1 ms, `bench/methods.sl`, self time from "Sort by top of stack" against the main
thread's own sample total — control and branch each sampled once, same dev commit `24a2cb0`, box at
92–94% idle, `pgrep -x java` empty.

| | control (sysl 0.0.123) | branch (sysl 0.0.124) |
|---|---|---|
| samples (main thread) | 283 | 453 |
| `Buf.push<Value>` self time | 9 / 283 = **3.2%** | 0 / 453 = **0%** |

**The mechanism is real and complete**: `Buf.push<Value>` does not appear anywhere in the branch's
sample at all — inlined away entirely — where it still cost 3.2% of self time on the control, built
from the same source with the previous compiler. That this does not translate into a best-of-9 win on
this tree is the finding to carry forward: `inline-fused`'s rewrite of the surrounding dispatch loop
changed what else is now on the hot path, and whatever `Buf.push<Value>` used to cost is being spent
elsewhere now rather than saved.

## What this closes and what stays open

**No shortlist line is struck by this pickup.** Item 1 (inlining `Buf.push`'s common path) was already
struck at 0.0.123; this is the same compiler mechanism carried one step further for the specific case
of a counted element, found and fixed on sysl's own side rather than from a slate profile. Item 8 (a
narrower `Value`, or NaN-boxing) is unaffected — `Buf.push<Value>`'s reach figure there was already
stale after 0.0.123 and the third sampled profile (dev `a642e9f`), and stays stale here for the same
reason: every compiler-level `Buf.push` change moves underneath that item without a slate-side change
to explain it. **A fresh sampled profile is owed before that item is next in line** — this pickup is a
second compiler-level move landing on top of `inline-fused` with no new profile taken since, so the
live ranking of what is left is not known with confidence.

**Nothing under `dev/` changed.** The whole of this item is `package.hocon`'s floor plus a newer
compiler, exactly as the 0.0.123 and 0.0.122 write-ups above were.
