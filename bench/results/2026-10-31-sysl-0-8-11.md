# slate on sysl 0.8.11, against 0.1.32 and 0.1.8

Every binary is a PGO build from `bench/pgo.sh`, and each comparison is `bench/alternate.pl 5`: the two
binaries run alternately, program by program, and the lowest of five rounds is kept. Times are
milliseconds. Taken under `caffeinate` at 93% idle before and after, which is a quiet box.

- **0.1.32** is the release on sysl 0.8.8 (`/opt/homebrew/bin/slate`).
- **dev** is dev at `237256b`, built with sysl 0.8.11. It is 0.1.32's tree plus the compiler move.
- **hoist** is dev with `bfbbe9b`, which takes an operator's answer into a local before pushing it.
  It ships in 0.1.33.
- **0.1.8** is the release tarball, the fastest slate has been.

0.8.11 drops the null check on every `Buf` access. **Instructions retired went UP by 1-3% even so**
(table below), so the gain is in cycles: the branches removed were taken often, and the instructions
added were cheap. sysl 0.8.12 targets the extra instructions: a `Buf` handle in a struct field is no
longer re-read after each count write.

**Read this one with the instruction counts, not the times alone.** The times move both ways by about
3%, which is close to the noise of a 5-round minimum. The instruction counts fall on every program
measured except `arith`, which is flat: the retain and release around each `push(op(...)?)` are gone.
**A plain `sysl build .` of the same change retires MORE instructions** (fib +1.2%, arith +6.6% on
0.8.8). Only PGO builds ship, so only PGO builds decide.

## Against 0.1.8: still 23.88% slower

| | geometric mean against 0.1.8 |
|---|---:|
| 0.1.32 | +30.97% (`2026-10-30-sysl-0-8-8.md`) |
| dev on 0.8.11 | +24.71% |
| hoist (0.1.33) | **+23.88%** |

`sorting` is the one program faster than 0.1.8 (-10.6%). The rest of the gap is the self-hosted sysl's
`Buf` handle, the extra dependent load on every access that 0.8.11 left in place; that fix is sysl's.
